# 🌐 Vinith — Developer Portfolio

A modern, responsive personal portfolio website built with **Next.js** and **Tailwind CSS** to showcase my skills, projects, experience, and journey as a Full Stack Developer.

🚀 **Live Portfolio:** [my-portfolio-sigma-amber-38.vercel.app](https://my-portfolio-sigma-amber-38.vercel.app/)

---

## ✨ About

This portfolio was designed and developed to provide a clean and interactive way to showcase my development skills and projects.

The website focuses on a modern **black and purple UI**, responsive layouts, reusable React components, and smooth animations.

---

## 🚀 Features

* 🎨 Modern black & purple UI
* ⚡ Built with Next.js App Router
* 📱 Fully responsive design
* 🧩 Reusable React components
* ✨ Smooth animations and hover effects
* 🔄 Infinite horizontal skills slider
* 👨‍💻 About Me section
* 🛠️ Skills section

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/vinithdc-jpg/MyPortfolio.git
```

### 2. Navigate to the project

```bash
cd MyPortfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in your browser

```text
http://localhost:3000
```

---

## 🖥️ Production Build

Create a production build:

```bash
npm run build
```

Start the production server:

```bash
npm start
```
